_Teste de calculo de notas em Python_

Este projeto simples e rápido foi desenvolvido para automatizar o cálculo de médias escolares e avaliar o desempenho acadêmico de alunos. Ele serve para demonstrar as notas de diferentes avaliações, usando as notas finais correspondentes a cada prova que o usuário fez em um cálculo de soma que determina se o estudante atingiu a pontuação mínima necessária para aprovação, caso ele não for aprovado é mostrada uma frase de erro avisando que o mesmo não atingiu a pontuação necessária.
